    The Sweden Central lab

    Configuration verified on 13 Sep 2026. This offline runbook does not query Azure or execute commands. Check current health in your terminal before each demo.

    Scope & cost controls

    Open the deployed lab

    The two store endpoints are HTTP demo sites, without production authentication. Use test data only.

    Stop & start AKS

    Restore active demo faults before stopping. Both websites go offline while AKS is stopped. SRE Agent, disks, and other retained resources continue billing.

    Allow 15-30 minutes between stopping and restarting. Starting resumes node compute charges; regional capacity can delay a restart. Start ahead of your demo.

    After starting, refresh AKS credentials, verify workloads and telemetry, and rediscover the website URLs. Starting does not restore scenario faults.

    Resume and acceptance checksCost and shutdown guide

    Observability & agent behavior

    Container Insights, Log Analytics, Application Insights, four one-minute log alert rules, and the Azure Monitor connector are configured. Grafana and managed Prometheus were omitted.

    Allow several minutes for telemetry and alert evaluation. Not every scenario necessarily triggers a configured rule. Check Azure Monitor Alerts and the agent's Incidents separately; a runner report does not prove that either stage occurred.

    The response plan routes matching high-priority Pet Store alerts to incident-handler in Review mode. cluster-health-monitor provides health checks. Review proposed write actions before approval.

    Outlook authorization is optional for email delivery. GitHub source-code analysis and Microsoft Learn MCP are not configured.

    Presenter guardrails

    • Prepare, inject one fault, collect fresh evidence, investigate, restore, verify.
    • Keep the two node pools fixed. Pending Pods is intentionally unschedulable.
    • Run CPU stress briefly. Stop the scenario after collecting enough evidence.
    • Compare event times with this injection; old restart counts are not proof of a new fault.
    • A green pod does not prove that checkout, networking, or order processing works.
    • The runner uses the current kubectl context before validation. ResourceGroupName alone does not select the cluster.
    • Repo shortcuts such as break-oom and fix-all assume the dev-container shell setup; these runbooks use explicit PowerShell commands.

    Costs while the lab exists

    VMs plus the SRE Agent baseline are approximately USD 493.48 per 730-hour month, before disks, networking, ACR, logs, alerts, and active agent usage. This is not a spending cap.

    Stopping AKS does not stop SRE Agent or all retained-resource charges. Stop/start and full lab teardown instructions remain in the cost guide. Recovery below does not delete Azure infrastructure or MongoDB storage.
